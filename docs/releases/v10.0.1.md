# PostFader V10.0.1

This patch improves MCP tool descriptions and selection guidance. It retains
134 tools and 8 resources, with unchanged executable tool behavior, argument
contracts, and safety annotations.

## Changes

- Expand 18 descriptions, including Piano Roll setup/writes/transforms, Plugin
  Atlas, mixer dB control, preset selection, mix plans, and Sound Selection.
- Explain prerequisites, effects, manual versus automatic execution, partial
  outcomes, and when to choose related tools.
- Clarify normalized parameter values versus displayed units and named options,
  immediate batches versus reviewed plans, and single presets versus palettes.
- Synchronize the MCPB catalog and add a tool-selection table to the reference.

## Upgrade and support

Install the 10.0.1 package and reconnect the MCP client so it reloads tool
metadata. Python users can run `pip install --upgrade postfader-fl-studio-mcp`.
Platform ZIP and MCPB users should use the matching assets on the release page
and follow the [setup guide](../setup.md).

The [V10 feature and platform limitations](v10.0.0.md) remain applicable.
This patch does not add live FL Studio qualification or Windows functionality.
No personal project files or prompts are included.

## Validation and artifacts

SDK compatibility tests and the MCP stdio inspection suite passed locally.
An AST comparison confirmed that server edits affect docstrings only. The
public-tree privacy check passed. The release workflow gates publication on
