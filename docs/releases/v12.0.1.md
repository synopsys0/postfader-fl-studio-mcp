# PostFader V12.0.1

V12.0.1 makes it clearer which tool applies which kind of change. Tool names,
arguments, results, and FL Studio behavior are unchanged from
[V12.0.0](v12.0.0.md).

## What's changed

- **Each apply tool names its input.** `processing_apply`,
  `sound_apply_palette`, and `review_apply_revision` now say that they apply
  only the result of their own planner (`processing_plan`,
  `sound_plan_palette`, and `review_plan_revision`).
  `project_apply_edits` applies edits you have already decided across several
  targets, and `run_execute` runs multi-step work. Each description points to
  the right sibling for the other cases.
- **The server instructions carry the same rule**, so your AI client sees it
  when it connects, and the [tool contracts](../tool-contracts.md) list it in
  "Choosing between related tools".

## Upgrade

The Universal Bridge script did not change, so FL Studio needs nothing new.

1. Close your AI client.
2. Upgrade PostFader: `pip install --upgrade postfader-fl-studio-mcp`, or use
   the platform ZIP or `.mcpb` from the release page.
3. Reconnect your AI client so it reloads the tool descriptions.

Coming from V11? Every tool was renamed in V12; see the
[V12.0.0 release notes](v12.0.0.md) for the full name table.

## Support and limits

Requirements and limits are the same as V12.0.0: FL Studio 2026 version
26.1.3 build 5336 or newer, Python 3.10 to 3.14, and Windows or macOS with one
virtual MIDI port. This release adds no new live FL Studio qualification; its
changes are covered by the hermetic test suite, which runs on Windows and
macOS with Python 3.10 and 3.14. No personal project files, audio, or prompts
are included.
