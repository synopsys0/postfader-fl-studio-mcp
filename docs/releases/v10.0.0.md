# PostFader V10 (10.0.0)

PostFader V10 is the 134-tool, 8-resource FL Studio MCP release previously
maintained on the dev branch. It includes the complete current feature set,
not only documentation changes. PostFader runs locally on Windows and macOS,
starts read-only, and never saves projects automatically.

## What is included

- Project inspection, mixer/routing/transport control, exported-audio analysis,
  Mix Doctor, reference comparison, deterministic composition, and MIDI export.
- Plugin Atlas product knowledge and runtime parameter discovery.
- Sound Selection with editable musical direction, coherent palettes, exact
  preset navigation, drum maps, anchors, and local history.
- Production Runs with readiness checks, sound-aware composition, semantic
  processing, durable SQLite checkpoints, and explicit restart recovery.
- Creation Review with bounce analysis, producer feedback and locks, bounded
  revision passes, before/after comparison, and delivery manifests.
- Structured Piano Roll note inspection through the armed script runtime.
- Named native-menu instrument/effect loading on macOS with instance readback.
- Background WAV rendering from an already-saved FLP, with status and cancellation.
- Windows persistence fixes and expanded package/privacy checks.

The dedicated vocal engine was removed before V10. General audio-analysis and
plug-in features remain. Current tool inventory: **134 tools and 8 resources**.

Upgrade the server and Universal Bridge together. Close MCP clients and FL
Studio, install the matching package, deploy its bridge, start FL Studio and
reload Universal Bridge, then reconnect the client and run the doctor. Configure
one bidirectional virtual MIDI endpoint. PostFader does not install a MIDI provider.
Prepare and manually arm the Piano Roll script once per MCP process before use.

## Support and evidence boundaries

Python 3.10–3.14 and FL Studio 2026 version 26.1.3 build 5336 or newer with
MIDI scripting API 44 or newer are the declared compatibility baseline.
Automated checks cover native Windows/macOS package builds, clean installation,
strict MCP schemas, synthetic audio, fake FL state, and refusal/recovery cases.
They do not establish live FL Studio or artistic quality.

The historical live matrix covers macOS 27 arm64 / FL 26.1.3 build 5336 and
Windows 11 x64 / FL 26.1.4 build 5589. Full live acceptance of V10's newer
native-loading, note-inspection, and saved-project rendering paths remains
pending. These paths are included with that limitation stated explicitly.

Native loading requires macOS Accessibility access and supported English menus.
Windows plug-in insertion, removal/reordering, automatic Playlist clip editing,
live audio capture, automatic project saving, and guaranteed rollback are unavailable.
Rendering exports saved state only and excludes unsaved changes. Unknown mutation
outcomes are not replayed. Local journals contain production data and must remain private.
