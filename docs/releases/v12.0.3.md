# PostFader V12.0.3

V12.0.3 supports MCP SDK 2.0 through 2.2 and preserves actionable guidance
when a tool refuses a request. It retains 85 tools and 8 resources, starts
read-only, and never saves your project automatically.

## What's changed

- **MCP SDK compatibility extends to `>=2.0.0,<2.3`.** SDK 2.1 and newer hide
  ordinary handler exception details. PostFader now explicitly exposes its
  known write-mode, authorization, stale-session, and edit-input refusals,
  plus command errors returned by the bridge. Unexpected Python, filesystem,
  and transport failures retain the SDK's default handling.
- **Refusal guidance remains useful.** A caller still sees how to request
  write mode, when Master needs explicit permission, and when an observed
  value has changed. Guards still refuse unsafe changes, and ambiguous writes
  are never replayed. Direct Python input checks retain their `ValueError`
  compatibility.
- **Compatibility CI exercises the actual upper boundary.** The newest-allowed
  SDK job now resolves the same `<2.3` bound as the package and also runs the
  verified-write refusal tests. Regression checks distinguish bridge command
  failures from unexpected exceptions.
- **CodeQL init and analyze both use 4.38.2.** Updating them together removes
  the configuration-version mismatch in the separate dependency PRs.
  Workflow permissions and scan configuration are unchanged.

## Choose a package

- **Windows or macOS:** use the matching generic ZIP for guided setup with any
  MCP client, or the matching Codex ZIP for Codex setup.
- **Claude Desktop:** install the matching platform setup first, then import
  the `.mcpb` extension. The extension does not install Universal Bridge or
  configure MIDI.
- **Python:** install `postfader-fl-studio-mcp==12.0.3` from PyPI. The wheel and
  source archive are also attached for Python-based installations.

## Upgrade

The Universal Bridge script is unchanged from V12.0.2.

1. Close your AI client.
2. Upgrade with `pip install --upgrade postfader-fl-studio-mcp==12.0.3`, or
   use the matching platform ZIP or `.mcpb` from this release.
3. Reconnect your client. Write-mode confirmation, session guards, and
   readback requirements continue to apply.

Coming from V11? See the [V12.0.0 name table](v12.0.0.md) for the tool renames.

## Support and evidence limits

Requirements remain FL Studio 2026 version 26.1.3 build 5336 or newer, Python
3.10 through 3.14, and Windows or macOS with one virtual MIDI port.
Historical live qualification used macOS 27.0 arm64 with FL Studio Producer
Edition 26.1.3 build 5336 and Windows 11 x64 with Producer Edition 26.1.4
build 5589. This patch adds no new live FL Studio or third-party plug-in
qualification.

The changes passed 1,148 checks across 63 hardware-free test files with each
of MCP SDK 2.0.0, 2.1.0, and 2.2.0. Hermetic coverage remains 76.4%. CI covers
Windows and macOS on Python 3.10 and 3.14, native installer dry-runs, clean
package installs, and MCP SDK compatibility. Those checks use synthetic
fixtures and fake FL APIs; they do not establish live audio quality or certify
every plug-in. No user projects, audio, or prompts are included.

## Signed release and artifact verification

Download from the [GitHub release](https://github.com/synopsys0/postfader-fl-studio-mcp/releases/tag/v12.0.3)
or [PyPI](https://pypi.org/project/postfader-fl-studio-mcp/12.0.3/).
This release uses a signed annotated Git tag. Previously published tags stay
unchanged. Verify the tag separately from the workflow's build-provenance and
SBOM attestations; see [supply-chain verification](../supply-chain.md).

Compare each download with `PostFader-v12.0.3-SHA256SUMS.txt`. The manifest
includes the wheel, source archive, MCPB, four setup ZIPs, and
`PostFader-v12.0.3-SBOM.cdx.json`.

On macOS or Linux, place the assets and checksum file in the same directory:

```sh
shasum -a 256 -c PostFader-v12.0.3-SHA256SUMS.txt
```

On Windows, calculate the chosen asset's digest and compare it with its line
in the checksum file:

```powershell
Get-FileHash .\PostFader-v12.0.3-Windows.zip -Algorithm SHA256
```

See [setup](../setup.md), [tool contracts](../tool-contracts.md), and the
[security policy](../../SECURITY.md). Report reproducible problems through
[GitHub Issues](https://github.com/synopsys0/postfader-fl-studio-mcp/issues).
